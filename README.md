## ✨ Overview

**BiteBuddy** is a full-stack, AI-first nutrition and fitness app that helps users take control of their health. Snap a photo of your meal and get instant nutritional analysis, chat with an AI nutrition coach, receive personalized weekly meal plans localized to your country's cuisine, track workouts, monitor water intake, and visualize your progress — all from one beautiful dashboard.

---

## 🚀 Features

### 🔍 AI Food Scanner
- **Image scanning** — Upload or capture a meal photo and get instant calorie & macro breakdown via Gemini Vision
- **Text analysis** — Describe your food in plain English and receive detailed nutritional estimates
- **Spoonacular cross-validation** — AI estimates are verified against the Spoonacular nutrition database for accuracy

### 📊 Nutrition Dashboard
- Real-time daily calorie & macro tracking (protein, carbs, fats, fiber, sugar, sodium)
- Visual progress rings and interactive charts
- Historical analytics with trend visualization

### 🗓️ AI Meal Planner
- **Personalized weekly plans** generated by Gemini, localized to your country's cuisine (India, USA, Mexico, and more)
- Supports multiple diet types: Balanced, Keto, Vegan, High-Protein
- **Smart plan adjustment** — Automatically re-balances remaining meals if you deviate from your targets or log a workout

### 🛒 Smart Shopping List
- Auto-generated grocery list from your active meal plan
- Check off items as you shop

### 💬 AI Nutrition Coach
- Conversational AI chatbot for nutrition, recipes, meal planning, and fitness questions
- Powered by Gemini 2.5 Flash with a custom BiteBuddy persona

### 🏋️ Workout Tracker
- Log workouts with exercises, sets, reps, and weight
- Tracks calories burned, total volume, and muscles trained
- Post-workout meal adjustments powered by AI

### 💧 Water Log
- Daily water intake tracking with quick-add buttons

### 🎯 Goals & Analytics
- Set and track nutrition & fitness goals
- Backend-calculated analytics for progress visualization

### 🔐 Authentication & Profiles
- JWT-based signup/login with secure password hashing (bcrypt)
- User onboarding flow to capture dietary preferences, country, age, weight, and fitness goals
- Persistent user profiles with customizable settings

## 🏗️ Architecture

BiteBuddy uses a **monorepo** structure with two backend services and a React frontend:

```
BiteBuddy/
├── frontend/          # React 19 + Vite SPA
│   ├── src/
│   │   ├── components/    # Reusable UI components (charts, layout, ui)
│   │   ├── pages/         # Page-level views (Dashboard, Scanner, Planner, etc.)
│   │   ├── hooks/         # Custom React hooks (useToast, etc.)
│   │   ├── data/          # Static data & constants
│   │   └── assets/        # Images & static assets
│   └── index.html
│
├── backend/           # Express.js API + FastAPI AI microservice
│   ├── app.js             # Express entry point
│   ├── main.py            # FastAPI entry point (AI services)
│   ├── config/db.js       # MongoDB connection (Atlas-ready)
│   ├── routes/            # Express route handlers (13 route files)
│   ├── models/            # Mongoose schemas (User, MealLog, WorkoutLog, etc.)
│   ├── controllers/       # Business logic controllers
│   ├── middleware/         # Auth middleware (JWT verification)
│   ├── services/          # Service layer
│   ├── meal_scan.py       # Gemini Vision food scanner + Spoonacular
│   ├── ai_personalize.py  # AI meal plan generation & adjustment
│   ├── shopping_ai.py     # AI shopping list generation
│   └── prompts.py         # System prompts for all AI models
│
├── api/               # Vercel serverless API entry
├── vercel.json        # Vercel deployment configuration
└── package.json       # Monorepo root package
```

### Data Flow

```
User → React Frontend → Express API → MongoDB (CRUD operations)
                      → FastAPI    → Google Gemini 2.5 Flash (AI features)
                                   → Spoonacular API (nutrition validation)
```

## ⚡ Getting Started

### Prerequisites

- **Node.js** ≥ 18
- **Python** ≥ 3.9
- **MongoDB** (local instance or [MongoDB Atlas](https://www.mongodb.com/atlas) free tier)
- **Google Gemini API Key** — [Get one here](https://aistudio.google.com/apikey)
- **Spoonacular API Key** *(optional)* — [Get one here](https://spoonacular.com/food-api)

### 1. Clone the Repository

```bash
git clone https://github.com/niharikakumari23/BiteBuddy.git
cd BiteBuddy
```

### 2. Set Up the Backend

```bash
cd backend

# Install Node.js dependencies
npm install

# Create a Python virtual environment & install AI dependencies
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
# source venv/bin/activate

pip install -r requirement.txt
```

### 3. Configure Environment Variables

Create a `backend/.env` file:

```env
# Required
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/BiteBuddy
GEMINIKEY=your_google_gemini_api_key
JWT_SECRET=your_jwt_secret_key

# Optional
SPOONACULAR_KEY=your_spoonacular_api_key
PORT=5000
```

### 4. Set Up the Frontend

```bash
cd ../frontend
npm install
```

*(Optional)* Create a `frontend/.env` file if your backend runs on a different host:

```env
VITE_API_URL=http://localhost:5000/api
```

### 5. Run the App

Open **two terminals**:

**Terminal 1 — Express Backend:**
```bash
cd backend
npm run dev
```

**Terminal 2 — FastAPI AI Service:**
```bash
cd backend
# Activate your venv first
uvicorn main:app --reload --port 8000
```

**Terminal 3 — React Frontend:**
```bash
cd frontend
npm run dev
```

The app will be available at **http://localhost:5173** (Vite default).

## 🌍 Deployment (Vercel)

The project is configured for **Vercel** deployment out of the box:

1. Connect your GitHub repo to [Vercel](https://vercel.com)
2. Set **Root Directory** to `./` (monorepo root)
3. Add environment variables in the Vercel dashboard:
   - `MONGODB_URI`
   - `GEMINIKEY`
   - `JWT_SECRET`
   - `SPOONACULAR_KEY` *(optional)*
4. Deploy — Vercel handles the frontend build and serverless backend routing via `vercel.json`

> **Important:** Whitelist `0.0.0.0/0` in your MongoDB Atlas Network Access settings for Vercel's dynamic IPs.
